# Transformer Reimplementation Study



## 📚 Introduction  
This repository is dedicated to the study and reimplementation of the **Transformer** architecture as introduced in the paper *"Attention is All You Need"*. The goal of this study is to gain a deep understanding of the Transformer model by reconstructing it from scratch, analyzing its core components, and experimenting with various configurations.

---

## 🎯 Objectives  
- Understand the theoretical background of the Transformer architecture.  
- Reimplement key components such as:  
  - Scaled Dot-Product Attention  
  - Multi-Head Attention  
  - Positional Encoding  
  - Encoder and Decoder Blocks  
- Compare performance with the original implementation.
